# แผนปรับ Webapp ให้ใช้งานบนมือถือได้ดี

## วัตถุประสงค์

ปรับหน้า Admin Webapp ให้ใช้งานบนมือถือได้ง่ายขึ้น โดยยังคงหน้าตา Desktop เดิมให้ใช้งานได้เหมือนเดิม และไม่กระทบการทำงานของ Android Player/API

## ขอบเขตงาน

- ปรับเฉพาะฝั่ง Webapp ในโฟลเดอร์ `web-ichicoolpay`
- เน้นหน้าที่ผู้ดูแลระบบใช้งานจริง ได้แก่ Dashboard, Devices, Media, Playlists, Playlist Edit, Upload, Assign Playlist และ Forms
- ไม่แก้ระบบฐานข้อมูล
- ไม่แก้ Android APK
- หลังจบแต่ละเฟสให้สร้างไฟล์สรุป `.md` สั้น ๆ ว่าทำอะไรไปแล้ว

## ปัญหาที่ตรวจพบปัจจุบัน

- เมนูด้านซ้ายเมื่อเปิดบนมือถือกินพื้นที่แนวตั้งมาก ทำให้ผู้ใช้ต้องเลื่อนผ่านเมนูก่อนเห็นข้อมูลหลัก
- ตารางข้อมูลหลายหน้าใช้การเลื่อนซ้ายขวา ซึ่งใช้งานได้แต่ไม่เหมาะกับมือถือ
- ปุ่มในคอลัมน์จัดการมีหลายปุ่มอยู่ใกล้กัน ทำให้กดยากและเสี่ยงกดผิด
- Header ด้านบนมีข้อมูลหลายส่วนและอาจเบียดกันบนจอเล็ก
- หน้าแก้ไขเพลย์ลิสต์มีทั้งฟอร์มและตารางในหน้าเดียว จึงควรจัดลำดับข้อมูลให้ชัดขึ้นบนมือถือ

---

## Phase 1: ปรับโครงหน้าและเมนูสำหรับมือถือ

### งานที่จะทำ

- ปรับ sidebar บนมือถือให้กลายเป็น header/menu แบบ compact
- ลดความสูงของส่วนแบรนด์และเมนูเมื่ออยู่บนมือถือ
- ปรับเมนูให้เรียงเป็นแถบปุ่มที่กดง่าย ไม่ยืดเป็นคอลัมน์ยาวเกินไป
- ปรับ active menu ให้มองเห็นชัด แต่ไม่กินพื้นที่
- ปรับ topbar ให้ชื่อหน้า, ชื่อผู้ดูแล และปุ่มออกจากระบบไม่เบียดกัน

### ไฟล์ที่คาดว่าจะกระทบ

- `web-ichicoolpay/app/views/layout/header.php`
- `web-ichicoolpay/app/views/layout/sidebar.php`
- `web-ichicoolpay/public/assets/css/admin.css`

### เกณฑ์ตรวจรับ

- เปิดบนมือถือแล้วเห็นเนื้อหาหลักเร็วขึ้น
- เมนูไม่ยาวจนบดบังหน้าจอแรก
- โลโก้และชื่อ `iCHI-COOL Play` ไม่แตกบรรทัดแบบผิดรูป
- Desktop ยังแสดง sidebar แบบเดิม

---

## Phase 2: เปลี่ยนตารางรายการเป็น Mobile Card

### งานที่จะทำ

- บนมือถือ เปลี่ยนตารางหลักให้แสดงเป็น card ต่อรายการ
- ใส่ label ของแต่ละข้อมูลใน card เช่น สถานะ, เห็นล่าสุด, เวอร์ชัน, เพลย์ลิสต์
- แสดงข้อมูลสำคัญที่สุดไว้ด้านบนของ card
- ยังคงรูปแบบตารางปกติบน Desktop

### หน้าที่จะปรับ

- Dashboard: รายการอุปกรณ์ล่าสุด
- Devices: รายการอุปกรณ์ทั้งหมด
- Media: รายการสื่อ
- Playlists: รายการเพลย์ลิสต์
- Playlist Edit: รายการสื่อในเพลย์ลิสต์

### ไฟล์ที่คาดว่าจะกระทบ

- `web-ichicoolpay/public/dashboard.php`
- `web-ichicoolpay/public/devices.php`
- `web-ichicoolpay/public/media.php`
- `web-ichicoolpay/public/playlists.php`
- `web-ichicoolpay/public/playlist-edit.php`
- `web-ichicoolpay/public/assets/css/admin.css`

### เกณฑ์ตรวจรับ

- ผู้ใช้มือถืออ่านรายการได้โดยไม่ต้องเลื่อนตารางซ้ายขวา
- ข้อมูลแต่ละรายการแยกกันชัดเจน
- ไม่มีข้อความล้นกรอบ
- Desktop ยังใช้ตารางแบบเดิม

---

## Phase 3: ปรับปุ่ม Action และฟอร์มให้กดง่าย

### งานที่จะทำ

- ปรับปุ่มจัดการบนมือถือให้เป็นปุ่มเต็มความกว้างหรือแบ่งกลุ่มชัดเจน
- เพิ่มระยะห่างระหว่างปุ่ม เช่น แก้ไข, กำหนดเพลย์ลิสต์, รีซิงก์ทันที, ปิดใช้งาน
- ปรับฟอร์มให้ช่องกรอกและปุ่มมีขนาดเหมาะกับการใช้นิ้ว
- ปรับหน้า Upload, Device Form, Assign Playlist และ Playlist Edit ให้ใช้ง่ายบนจอเล็ก

### ไฟล์ที่คาดว่าจะกระทบ

- `web-ichicoolpay/public/device-form.php`
- `web-ichicoolpay/public/media-upload.php`
- `web-ichicoolpay/public/assign-playlist.php`
- `web-ichicoolpay/public/playlist-edit.php`
- `web-ichicoolpay/public/assets/css/admin.css`

### เกณฑ์ตรวจรับ

- ปุ่มไม่เบียดกันและกดผิดยาก
- ฟอร์มไม่ล้นขอบจอ
- ช่องเลือกเพลย์ลิสต์/สื่ออ่านข้อความได้ชัด
- ปุ่มหลักของแต่ละหน้ามองเห็นง่าย

---

## Phase 4: ปรับรายละเอียด Responsive และ Empty/Error State

### งานที่จะทำ

- ปรับระยะขอบ, ขนาดตัวอักษร และช่องว่างของหน้า mobile ให้สมดุล
- ปรับข้อความแจ้งเตือน success/error ให้อ่านง่ายบนมือถือ
- ปรับหน้าไม่มีข้อมูล เช่น ยังไม่มีอุปกรณ์, ยังไม่มีสื่อ, ยังไม่มีเพลย์ลิสต์ ให้ดูไม่หลุด layout
- ตรวจสีและ contrast ของเมนู/ปุ่มบนมือถือ

### ไฟล์ที่คาดว่าจะกระทบ

- `web-ichicoolpay/public/assets/css/admin.css`
- อาจแตะไฟล์หน้า `.php` เฉพาะกรณีต้องเพิ่ม class หรือ data-label

### เกณฑ์ตรวจรับ

- หน้าไม่มีข้อมูลไม่ดูโล่งหรือแตก
- ข้อความแจ้งเตือนไม่ล้น
- สีเมนูและปุ่มอ่านง่าย
- ใช้งานได้ทั้งมือถือแนวตั้งและแนวนอน

---

## Phase 5: ตรวจสอบก่อนนำขึ้น Server

### งานที่จะทำ

- ตรวจ PHP syntax ทุกไฟล์
- ตรวจว่าไม่มีการแก้ API ที่ Android ใช้งานอยู่
- สรุปรายชื่อไฟล์ที่ต้องอัปโหลดขึ้น server
- สร้างไฟล์สรุปผลการปรับ mobile UI

### เกณฑ์ตรวจรับ

- PHP syntax ผ่านทั้งหมด
- ไม่ต้อง build APK ใหม่
- ได้รายการไฟล์ deploy ชัดเจน
- พร้อมนำไปทดสอบบน server จริง

---

## แนวทางการพัฒนา

- ทำทีละเฟสและรออนุมัติก่อนเริ่มเฟสถัดไป
- หลังจบแต่ละเฟสจะสร้างไฟล์สรุปใน `web-ichicoolpay/docs/`
- Desktop ต้องไม่เสียรูปจากการปรับ mobile
- API สำหรับ Android Player ต้องไม่เปลี่ยนพฤติกรรม
